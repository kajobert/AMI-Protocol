# AMI-Protocol

> **Trust instead of Authority.**

AMI-Protocol defines the transport-agnostic communication layer for [AMI — Artificial Mind Full Intelligence](https://github.com/kajobert/AMI).

GitHub is one possible AMI node/transport, not the protocol itself. The protocol should preserve meaning across GitHub, local agents, MCP, servers, future peer-to-peer transports and other communication channels.

## First design targets

- identity and node metadata;
- capability advertisement;
- task/request envelopes;
- result and evidence envelopes;
- provenance and verification links;
- contribution/trust assertions;
- explicit uncertainty and status.

The first implementation should stay small and interoperable. Historical protocol ideas remain evidence until archaeology validates them.
